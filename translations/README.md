# Multilingual Bot Pack

This directory contains bot templates and examples for creating bots in various non-English languages.

## Available Language Templates

- Spanish (es)
- Chinese (zh-CN)
- [Add your language here]

## Getting Started

1. Choose a language template from the available options
2. Copy the template to your working directory
3. Modify the bot content and logic as needed
4. Test your bot thoroughly

## Contributing

To add a new language template:
1. Create a new directory with the language code (e.g., `fr` for French)
2. Add your bot template files
3. Update this README
4. Submit a pull request
